## 硬性规则

1. **装软件走 pacman/AUR 正规渠道**，禁止往用户目录随手 cp 二进制。唯一例外：用户自己项目编译的产物放 `~/.local/bin/`（如 alt-tab-global、lyricsd）。
2. **sudo 密码必须由用户本人输入**：用 `SUDO_ASKPASS=/home/torin/.local/bin/gui-askpass sudo -A <cmd>`，会弹 zenity 窗口。禁止向用户索要密码明文。
3. **改系统/插件前先备份**（`.bak` 同目录备份或 git），改完告知回滚方法。
4. **本机有手写补丁勿动**：`~/.config/omarchy/plugins/rosakodu.dock/scripts/dock-minimize.py`（`reveal_user_drawer()` 补丁）。
5. **别重新发明已踩过的坑**：先读 docs/03 的教训清单和 docs/01 的"勿动清单"。
6. 调研先行：任何"应该能行"的方案，先在本机验证一条最小路径再铺开。
7. 做不完就说做不完，**禁止把未验证的东西说成已完成**。
