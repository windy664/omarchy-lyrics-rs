# 02 — 原插件架构分析（crmne/omarchy-lyrics v1.2.8）

语言构成：Python ~48%（后端脚本）、QML ~30%（界面）、JavaScript ~22%（QML 逻辑）。

## 仓库结构

```
manifest.json      # 插件清单（schemaVersion 1）
Service.qml        # service 入口：常驻服务，连 MPRIS、调度歌词抓取
BarWidget.qml      # 顶栏小部件入口：紧凑模式一行歌词 + 点击展开面板
LyricsView.qml     # 展开后的歌词阅读面板（逐行高亮、跟随滚动）
Model.js           # 数据模型/逻辑胶水
Artwork.qml/.js    # 专辑封面处理（含安全修复：限制下载大小、不读重定向 body）
bin/               # Python 后端脚本（QML 通过进程调用）
  lrclib           # 歌词抓取：查 LRCLIB，get 按精确元数据 / search 返回候选
  artwork          # 封面下载：从 MPRIS 的 ARTWORK_URL 下载（走环境变量传 URL）
tools/ tests/      # 开发工具与测试
```

## 数据流

```
Spotify (MPRIS/DBus: org.mpris.MediaPlayer2.*)
    │  PositionLookup + Metadata(artist/title/album/duration/artworkUrl)
    ▼
Service.qml ──子进程──▶ bin/lrclib (Python)
    │                     │ GET https://lrclib.net/api/get 或 /api/search
    │                     ▼ 带时间戳的 LRC 行 [{time, text}, ...]
    ▼
Model.js 按播放进度定位当前行 ──▶ BarWidget.qml（紧凑：一行）/ LyricsView.qml（展开：全文+高亮）
```

## manifest.json 关键字段（重写时要对齐的契约）

```jsonc
{
  "schemaVersion": 1,
  "id": "crmne.lyrics",
  "kinds": ["service", "bar-widget"],
  "keepLoaded": true,
  "entryPoints": { "service": "Service.qml", "barWidget": "BarWidget.qml" },
  "barWidget": {
    "defaultSection": "right",
    "allowMultiple": false,
    "defaults": { "hideWhenIdle": true, "panelWidthPercent": 30, "panelHeightPercent": 85 },
    "schema": [ /* 设置项声明：key/type(integer|boolean)/label/min/max/defaultValue */ ]
  }
}
```

要点：
- `kinds` 同时含 service 和 bar-widget → 需要两个 QML 入口。
- `barWidget.schema` 是设置声明，Omarchy 会按它渲染设置 UI 并持久化。**读回时类型不可信**（docs/03）。
- 设置项语义：`hideWhenIdle`（无播放时隐藏小部件）、`panelWidthPercent`/`panelHeightPercent`（展开面板尺寸）。

## 歌词来源

- **LRCLIB**（https://lrclib.net ）：免费开放的带时间戳歌词库，无需账号。
  - `/api/get`：按 artist/title/album/duration 精确匹配
  - `/api/search`：模糊搜索返回候选（元数据不理想时兜底）
  - 返回 synced lyrics（LRC 行级时间戳）和 plain lyrics 两种
- 封面：MPRIS `Metadata` 里的 `mpris:artUrl`。

## 可借鉴 / 应抛弃

| 原插件 | 处理 |
|--------|------|
| manifest 契约、LRCLIB API 用法、MPRIS 字段语义 | 直接借鉴（这部分是协议，语言无关） |
| Python bin/ 脚本 | 抛弃，Rust 后端等价重写 |
| hideWhenIdle 读取逻辑（字符串/布尔混淆 bug 所在） | 抛弃，见 docs/03 的教训 |
| 展开面板的尺寸自适应逻辑（panelWidth/HeightPercent） | 参考交互设计 |
